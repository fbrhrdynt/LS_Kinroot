# Changelog

## 0.1.0 — 2026-10-29

First greenfield KinRoot release.

- Introduced an Indonesian family workspace with dashboard, member directory, profiles and stories.
- Added full member create/edit/delete with local photo resizing.
- Added explicit biological, step, adoptive, guardian and unconfirmed relationships.
- Added marriage, nonmarital partnerships, former partnerships, widowhood status and cousin marriage.
- Implemented couple-centered shared biological branches and orthogonal sibling buses.
- Protected the canonical C–G–H–I example from false biological parentage.
- Added one-parent routes, multiple-partner crosslinks and obstacle-aware connector routing.
- Added drag, pinch, wheel, keyboard navigation, zoom and fit.
- Added validated local persistence, automatic previous-state backup, undo and corrupt-record recovery.
- Added JSON import/export, CSV export, SVG export and print layout.
- Added responsive mobile bottom navigation, labeled forms, focus trapping and reduced-motion support.
- Added automated domain, routing and persistence checks.

## 0.2.0 — 2026-10-29

Added the Vinext Worker backend, D1 cloud families and memberships, R2 private photos, host-managed identity, family creation/join/switch, owner/editor/viewer roles, hashed expiring single-use invitation links, membership administration, revision conflict protection, cloud refresh, and a 16-person fictional promotional demo with generated portraits and complete stories. Preserved v0.1.0 browser data for explicit import. Existing Site audience remains unchanged. Authentication is through ChatGPT, with Google/Apple on its sign-in page; separate direct provider OAuth is not claimed.

## 0.2.1 — 2026-10-29

Removed the demo/cloud workspace announcement banner, visible example ID letters, raw member IDs in profile headings and selection labels, and personal-name placeholders. Added a clean empty starting family and neutral family-name placeholder. Retained creator credit only in the footer. Promotional data is now a test fixture rather than an automatic application seed. Documented the Cloudflare/Work runtime boundary for a future VPS migration.
